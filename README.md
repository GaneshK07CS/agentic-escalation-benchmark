# agentic-escalation-benchmark

Agentic Escalation Benchmark (AEB)
Measuring When AI Agents Know They Shouldn’t Act Alone
Research proposal — benchmark design for measuring whether LLM agents choose the correct action 
mode (act / clarify / escalate / stop) in ambiguous, partially-specified operational tasks.
Most agent evaluation measures task completion alone, which rewards agents that always attempt the task 
even when they lack sufficient information or authority to act safely. AEB targets the case that both 
completion benchmarks and refusal benchmarks miss: plausible, non-harmful requests where the correct 
behavior is still not to act independently.
Written for the Mercor Research Fellowship. Status: proposal stage — pilot inter-rater labeling pass and 
cross-model evaluation planned next.
